A custom playable race mod for Songs of Syx featuring agrarian-focused chickens.

<strong>Pros</strong>
<ul>
<li>Excellent at farming and orchards</li>
<li>Innate slash damage capability</li>
<li>Actually like mud buildings</li>
</ul>
<strong>Cons</strong>
<ul>
<li>Terrible crafters</li>
<li>Poor researchers/administrators</li>
<li>OK with cannibalism</li>
</ul>

<h4>Requirements</h4>
<ul><li>Songs of Syx v71</li></ul>
</p>
